
#  CRUD MUNDO

##  Sobre o Sistema

O **CRUD MUNDO** é um sistema web desenvolvido com o objetivo de praticar as principais operações de gerenciamento de dados em um banco de dados, conhecidas como **CRUD**:

* **Create** — Criar;
* **Read** — Ler;
* **Update** — Atualizar;
* **Delete** — Excluir.

O sistema permite o gerenciamento de informações relacionadas a **países, cidades e idiomas**, possibilitando realizar o cadastro, consulta, atualização e exclusão dos dados.

O projeto tem como objetivo colocar em prática conceitos de **desenvolvimento web**, **integração entre aplicação e banco de dados** e **manipulação de informações** por meio das operações fundamentais de um CRUD.

---

##  Problema 

O sistema busca proporcionar uma forma organizada de **cadastrar e gerenciar informações sobre países, cidades e idiomas**, permitindo que os registros sejam manipulados de maneira prática.

Além disso, o projeto possui finalidade acadêmica, sendo utilizado para praticar a integração entre uma aplicação web e um banco de dados, aplicando na prática as operações de criação, leitura, atualização e exclusão de registros.

---

## Tecnologias Utilizadas

O projeto foi desenvolvido utilizando:

* **HTML5** — Estruturação das páginas;

## Funcionalidades

O **CRUD MUNDO** permite o gerenciamento de informações relacionadas a países, cidades e idiomas.

### Países

* Cadastrar países;
* Consultar países;
* Atualizar informações;
* Excluir registros.

### Cidades

* Cadastrar cidades;
* Consultar cidades;
* Atualizar informações;
* Excluir registros.

### Idiomas

* Cadastrar idiomas;
* Consultar idiomas;
* Atualizar informações;
* Excluir registros.

### Operações CRUD

| Operação   | Função                           |
| ---------- | -------------------------------- |
| **Create** | Cadastrar novos registros.       |
| **Read**   | Consultar registros existentes.  |
| **Update** | Atualizar registros cadastrados. |
| **Delete** | Excluir registros.               |

## Como Executar o Projeto

Para executar o projeto, é necessário possuir um ambiente capaz de executar **PHP** e **MySQL**.

### Pré-requisitos

* PHP;
* MySQL;
* Servidor web compatível com PHP;
* Navegador web.

### Execução

1. Baixe ou clone este repositório.

2. Configure um servidor web para executar os arquivos PHP do projeto.

3. Configure o banco de dados **MySQL** utilizado pela aplicação.

4. Importe o banco de dados disponibilizado no projeto, caso exista um arquivo `.sql`.

5. Configure os dados de conexão com o MySQL nos arquivos responsáveis pela conexão do sistema.

6. Inicie o servidor web e o MySQL.

7. Acesse o endereço da aplicação pelo navegador.

> **Observação:** as configurações de conexão podem variar de acordo com o ambiente utilizado para executar o projeto.
